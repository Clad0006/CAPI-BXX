# Projet CAPI

## Lancer l'application
Pour lancer l'application, suivez les étapes ci-dessous :

1. `git clone https://github.com/Clad0006/CAPI-BXX` : Clonez le dépôt Git de l'application sur votre machine locale.
2. `cd CAPI-BXX` : Accédez au répertoire du projet.
3. `mvn spring-boot:run` / `mvnw spring-boot:run` : Lancez l'application en utilisant Maven.
4. Ouvrez votre navigateur et accédez à `http://localhost:8080` pour voir l'application en action.

## Lancer les tests
Pour exécuter les tests de l'application, utilisez la commande suivante :
- `mvn test` / `mvnw test`
